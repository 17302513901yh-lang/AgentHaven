## AgentHaven 0.3.0

One local work board for AI agents from every vendor, people, scripts and training jobs.

### New
- **Claims that expire**: a task goes back on the board, with a note, when its agent shows no sign of life for 30 minutes. Crashed sessions no longer hold work or files.
- **`next_task`**: hands an agent the most important task it can start now, using priority (P0 to P3), dependencies, free files and the agent's skills.
- **Dependencies** between tasks, with a cycle check.
- **Acceptance criteria and review**: a task is done only when all criteria are checked, and tasks marked for review need approval from someone else. Only the agent holding a task, or a human, can change or finish it.
- **Progress, usage, metrics and budgets** per task: tokens, cost, loss, accuracy, tests passed and more, with charts. A task that passes its budget is blocked.
- **Agents panel**: kind (LLM, human, neural network, script), vendor, model, skills and who is online.
- **WORKBOARD.md**: share the board as a Markdown file in your project folder. Any agent that can edit files joins by writing `name: command` lines in the Inbox. Everything is also appended to `LOGBOOK.md`.
- **HTTP API for scripts**: send `X-AgentHaven-Agent: <name>`. See `examples/report_progress.py` for a training-loop reporter.
- **MCP plugin**: 22 tools, and the agent's vendor is detected from its client.
- **One-click connect** for Gemini CLI and Codex, next to Claude Desktop, Cursor and Windsurf.
- **Dashboard**: live updates, board summary, richer cards, a task dialog with criteria, comments, metric charts and history, filters, keyboard shortcuts (`n`, `/`) and a phone layout.

### Fixes
- Paths with `//`, `./` or `../` are normalised, so overlapping file claims are always caught.
- Deleting a task without a version is a validation error instead of a misleading conflict.
- An unknown CLI command exits with an error.

### Upgrading
Workspaces from 0.2 are upgraded automatically when they are read.

### Limitations
The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*. Automatic updates on macOS need a signed and notarized build.
