## AgentHaven 0.6.0

Seamless: agents connect by themselves, and the desktop app updates from the dashboard.

### New
- **Agents connect by themselves.** At start, the desktop app finds the agent apps on your computer and adds AgentHaven to their MCP settings: Claude Desktop, Claude Code, Cursor, VS Code (Copilot), Windsurf, Gemini CLI, Codex and LM Studio. A banner says which ones; restart those apps once.
  - Apps you install later are connected within 10 minutes.
  - Connections that point to an old or moved copy of AgentHaven are repaired.
  - Every other setting is kept, files with comments and trailing commas are read, and a `.agenthaven-backup` copy is made. A settings file that cannot be read is reported and never overwritten.
  - Claude Code with the AgentHaven plugin is left alone, so its tools do not show twice.
  - On macOS nothing is connected while the app runs from the mounted `.dmg`: move it to Applications first.
- **Connect agents panel.** The header button shows how many agents are connected. The panel lists every app with its state, *Connect*, *Reconnect* and *Disconnect*, and a switch for the automatic mode. An app you disconnect stays disconnected.
- **`agenthaven connect`** connects every installed agent app from a terminal: `agenthaven connect`, `agenthaven connect cursor codex`, `agenthaven connect --list`, `agenthaven connect --off cursor`. Through `npx -y github:laaielichter/AgentHaven connect`, entries start AgentHaven through npx, so a cleared npx cache does not break them.
- **Updates in the dashboard.** An update bar with download progress and speed, *What's new*, *Restart and update*, *Later* and *Skip this version*. A version button in the header opens the update settings, with *Check now* and automatic checks (at start and every 6 hours). After an update, the dashboard says once which version you came from.
  - Windows: the update downloads in the background and installs silently on restart, or when you quit.
  - macOS, unsigned: macOS does not let an unsigned app replace itself, so AgentHaven downloads the new `.dmg` to Downloads, opens it, and you drag AgentHaven onto Applications. Signed builds update by themselves.
- `examples/report_progress.mjs`: the training-loop reporter for Node.js 20+, without dependencies. Thanks to @Daiyuanranfeng for this and for the careful end-to-end test! (#14)

### Security
- Only the person at the dashboard can change agent connections; requests from agents (`X-AgentHaven-Agent`) are refused.
- The dashboard page reaches the desktop app only through the update calls, and only from the app's own local address.

### Updating from 0.5
- Windows: 0.5 finds this version and offers to restart.
- macOS: 0.5 cannot install updates while unsigned. Download the `.dmg` below once; from 0.6 on, the app does the download for you.

### Limitations
- The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
- The Claude Code plugin needs Node.js 20 or later. Without Node.js, the desktop app connects Claude Code for you instead (when the plugin is not installed).
