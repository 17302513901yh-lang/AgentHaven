## AgentHaven 0.5.0

A smarter plugin for agents: Claude Code now respects file claims on its own, and every agent spends fewer tokens on AgentHaven.

### New
- **Claude Code plugin.** Install it in Claude Code with `/plugin install agenthaven --marketplace laaielichter/agenthaven` (or `/plugin marketplace add laaielichter/AgentHaven`, then `/plugin install agenthaven@agenthaven`). It needs Node.js 20 or later.
  - Slash commands: `/agenthaven:next`, `/agenthaven:handoff`, `/agenthaven:review`, `/agenthaven:status`, `/agenthaven:plan` and `/agenthaven:dream`.
  - **SessionStart hook**: every session starts with the goal, the board, your tasks, what is up next and which files others are working on.
  - **PreToolUse hook**: an edit to a file another agent has claimed is refused, with who holds it and what to do instead. File claims are now binding in Claude Code.
  - **Stop hook**: before stopping while holding a task it has gone quiet on, the agent is asked once to report progress or hand the task off.
  - The hooks fail open: if AgentHaven cannot answer, Claude Code carries on.
- **Tool profiles.** Sessions start with 19 core tools instead of 39, which saves 43% of the tokens spent on tool descriptions. `enable_tools` adds `code`, `review`, `plan`, `team`, `lead` or `dream` and tells the client its tool list changed. Profiles also follow the role (lead, review skill, a configured repository). Use `--tools all` for clients that do not refresh their tool list.
- **Tool annotations** mark read-only tools, so clients can run them without asking, and mark `delete_task` as destructive.
- **Compact results** use about 30% fewer tokens, and clients on MCP 2025-06-18 or later also get `structuredContent`.
- **MCP prompts** (`next`, `handoff`, `review`, `status`, `plan`, `dream`) appear as slash commands in clients that support prompts.
- **One board name per session.** Two sessions with the same agent name become `claude-code` and `claude-code#2`, each with its own claims and leases. A session frees its name when it ends.
- `agenthaven --version`. Thanks to @Daiyuanranfeng, our first outside contributor! (#11)
- `agenthaven hook session-start|pre-tool-use|stop` for other editors with the same hook shape.
- The dashboard has a ★ Star link, and says thank you once, after your agents finish five tasks.

### Changed
- Agents connected before 0.5 start with the core tools. A dreaming agent calls `enable_tools` with `["dream"]` (its instructions now say so); or start any agent with `--tools all` for the old behaviour.

### Limitations
- Two Claude Code sessions in the same folder count as one agent for the edit hook, so they do not block each other. Give parallel sessions their own worktree.
- The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
