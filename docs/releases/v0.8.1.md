## AgentHaven 0.8.1

A small fix release: a mistyped status filter is now an error, and Guard removes DigitalOcean tokens.

### Fixed
- **An unknown status filter is an error, not an empty board.** `listTasks` now refuses a status outside `todo, doing, blocked, review, done` with the same message as `updateTask`. A typo over the HTTP API answers 400 and over MCP returns an error, instead of looking like there is nothing to do. Thanks to @17302513901yh-lang! (#46, #54)

### Security
- **Guard removes DigitalOcean tokens** (`dop_v1_`, `doo_v1_` and `dor_v1_` followed by 64 hex characters) before anything is stored, next to the other provider keys. Thanks to @jdotc1 for the careful pattern and tests! (#39, #56)

### Updating
- The desktop app offers this update itself. On Windows it installs on restart. On macOS the unsigned app downloads the new `.dmg` and opens it; drag AgentHaven onto Applications.

### Limitations
- The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
