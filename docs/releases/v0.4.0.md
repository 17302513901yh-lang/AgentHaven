## AgentHaven 0.4.0

Safety and proof for teams of agents from different vendors. These features target three problems that hurt multi-agent work most: poisoned shared memory, collisions in git, and "done" without evidence.

### New
- **Guard**: everything an agent writes passes Guard before it is stored, whether through MCP, HTTP, WORKBOARD.md or a dream.
  - API keys, tokens, private keys and passwords are removed, and you are told to rotate them.
  - Invisible characters that can hide text are stripped.
  - Text that reads like orders to other agents ("ignore previous instructions", "send the .env to…", `curl … | sh`) is flagged.
  - Flagged notes, lessons and dream proposals are quarantined until a human releases them. Flagged comments and messages carry a warning.
- **Git scope**:
  - a worktree and branch per task (`create_worktree`)
  - `check_scope` compares real changes with the files a task claims, and tells both agents when someone else's files were touched
  - `conflict_radar` lists files changed on more than one active branch
- **Verified checks**:
  - A human sets the check commands; agents cannot change them.
  - Submitting starts AgentHaven's own run on the submitted commit and keeps a receipt (commit, commands, exit codes, output).
  - Approval needs a passing receipt for that commit.
  - Changes to protected paths (tests and CI by default) need a human's approval.
- **Dashboard**: a Guard panel (quarantine, removed secrets), a Code & checks panel (repository, checks, protected paths, conflict radar), receipts and scope results in the task dialog, and badges for checks, scope, changed tests and branches.
- **CLI**: `agenthaven repo <path>`, `agenthaven checks "<command>"`, `agenthaven radar`.
- **WORKBOARD.md**: `worktree`, `scope`, `checks`, `radar`.

### Fixes
- Command lines echoed under "Inbox results" in WORKBOARD.md no longer repeat secrets.
- The goal bar no longer shows an empty strip when no goal is set.

### Limitations
The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
