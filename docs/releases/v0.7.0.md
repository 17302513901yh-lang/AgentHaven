## AgentHaven 0.7.0

A closer look at the board from the terminal, and Guard recognises more keys.

### New
- **`agenthaven status`** prints a short summary of the board: the goal, counts per status, who works on what and what waits on a human. It works with `--workspace` like the other commands. Thanks to @IG-ABHINAV for this, their first contribution to AgentHaven! (#16, #28)
- **`agenthaven tools`** lists the MCP tool profiles, and `agenthaven tools <profile>` describes each tool in one line. Both work without starting a server. Thanks to @Daiyuanranfeng, who already gave us `--version` and the Node.js progress reporter, for another useful one! (#19, #29)

### Security
- **Guard removes more provider keys** before anything is stored: Groq (`gsk_...`), SendGrid (`SG....`, including keys that end in a hyphen) and Replicate (`r8_...`) join the list, and the README's list of covered keys is complete again. Thanks to @jdotc1 for the careful patterns and the tests that make sure normal text is not touched, their first contribution to AgentHaven! (#7, #31)

### Updating
- The desktop app offers this update itself. On Windows it installs on restart. On macOS the unsigned app downloads the new `.dmg` and opens it; drag AgentHaven onto Applications.

### Limitations
- The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
