## AgentHaven 0.8.2

A small security release: Guard removes more secrets before anything is stored.

### Security
- **Guard removes the token in `Authorization` headers** (`Bearer`, `Token` and `Basic`, in any letter case, also inside `curl -H '...'`), keeping the header name and scheme. Values of 16 or more characters that another rule already removed are not reported twice, and ordinary prose about Bearer tokens is left alone. Thanks to @jdotc1! (#41, #65)
- **Guard fully redacts quoted passwords and passphrases**, including spaces and escaped quote characters, while preserving the surrounding quotes. Thanks to @jdotc1! (#63, #64)
- **Guard redacts quoted JSON/YAML secret assignments** such as `"password": "..."` and `"api_key": "..."`, preserving the key names and surrounding quotes, also when the value contains escaped quotes. Short values and already-redacted placeholders stay unchanged. Thanks to @jdotc1! (#45, #60)
- **Guard removes Shopify access tokens** (`shpat_`, `shpca_`, `shppa_` and `shpss_` followed by 32 hex characters) before anything is stored, next to the other provider keys. Thanks to @jdotc1! (#40, #59)

### Updating
- The desktop app offers this update itself. On Windows it installs on restart. On macOS the unsigned app downloads the new `.dmg` and opens it; drag AgentHaven onto Applications.

### Limitations
- Guard recognises known patterns; it cannot find every possible secret, so keep real credentials out of notes where you can.
- The installers are not signed yet. On Windows choose *More info → Run anyway*; on macOS right-click the app and choose *Open*.
