## AgentHaven 0.2.0

A local desktop workspace where AI agents share project knowledge, coordinate tasks and hand work to each other.

- Windows desktop installer (x64 and arm64) and universal macOS DMG/ZIP.
- Live task board with create, edit, delete, drag-to-move and isolated workspaces.
- MCP plugin with 11 tools for tasks, shared notes, activity and handoffs.
- File claims warn cooperating agents about overlapping work; they do not lock files in external editors.
- One-click configuration for Claude Desktop, Cursor and Windsurf, with config backups.
- GitHub release update support, plus optional signing and notarization.

### Verification and limitations

Lint and all 10 tests passed on Windows, macOS and Ubuntu CI. Both native packaging jobs and CodeQL passed. The downloaded artifact ZIPs passed integrity checks.

Signing certificates were not supplied. Treat these as unsigned test builds. Installed-app interaction, platform trust prompts, actual Claude Desktop tool discovery and auto-update have not been smoke-tested on Windows or macOS. macOS auto-update requires a signed and notarized build.

This release is intentionally a draft until the owner completes native smoke testing and chooses to publish it.
